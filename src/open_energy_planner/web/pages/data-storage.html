After migration and successful startup checks, the app resumes automatically using the new database. Planning may wait for fresh Home Assistant measurements and its other required inputs. The original database is retained but is no longer updated.

Database migration

Recovery instructions

The original database is retained. Before release, use Restore previous database. After release, returning requires a new migration to preserve new data.

If the app does not reconnect, keep this screen open. If the app cannot start, stop it and add --recover-storage to its normal startup command, keeping the same data directory. This is available only before release. For a Home Assistant app, enable recover_storage in the app configuration and start the app. Disable it after the original database is restored. This option never reverts a released migration. Never publish connection files or passwords.
