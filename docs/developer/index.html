Open Energy Planner

A ready-to-use development environment

Open the project in VS Code. Its Dev Container prepares Python, the solver, code checks and a separate Home Assistant test installation automatically.

  1. Install VS Code, Dev Containers and Git. Start Docker with Linux containers.
  2. Use the project URL below, or enter a fork or branch you can access.
  3. Open in VS Code, confirm its clone/trust prompts and wait for setup.

Private repositories require GitHub access inside VS Code. No token belongs in this field.

Open in VS Code

After setup

Open the local test Home Assistant at http://127.0.0.1:8123. Developer login details are in .local/developer.json inside the checkout. The EMS uses synthetic inputs and virtual commands.

Developer guide

If the button does not open VS Code

In VS Code run Dev Containers: Clone Repository in Container Volume... and paste your repository URL. For an existing checkout, choose Dev Containers: Reopen in Container.

The URL is processed in this browser only. This page collects no credentials or analytics. GitHub Pages hosting is optional. Provisioning runs locally.
